## Задача

Вывести на  отдельной странице список сотрудников за определенный день\промежуток дней с их проектами\задачами и трудозатратами  учтенными в них.
в таком формате (фио сотрудника - отдел его - проект - задача - трудозатрата - день когда былы внесены часы)

## Решение

Сделал отдельным компонентом и вывод через grid.  
Сортировка
- ИД
- Затраченное время
- Дата

Фильтрация
- Дата (селектор даты)
- Сотрудник (селектор)
- Задача (по подстроке)
- Проект (селектор)

Постраничка

Весь код оформлен в D7 с соблюдением стандартов разработки Битрикс.  
Решением является сам компонет и его вызов в /timesheet/index.php
